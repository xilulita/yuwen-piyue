# 智批语文 · AI 批改工作台

上传学生语文试卷照片，调用你自己配置的 AI 视觉接口自动批改，白板红笔标注、错题分析、家长小结、AI 分层出题、一键导出训练 PDF。纯本地运行，数据不出本机（除发送给你自己配置的 AI 接口）。

![界面](https://img.shields.io/badge/Python-3.9%2B-blue) ![依赖](https://img.shields.io/badge/依赖-reportlab-green)

## 快速开始

```bash
pip install reportlab
python app.py
```

Windows 可直接双击 `启动.bat`。启动后自动打开 http://127.0.0.1:8765/ 。

首次使用：右上角「⚙ AI 接口」填一次你的 OpenAI 兼容视觉接口（Base URL / 模型 / API Key），永久记忆。推荐 qwen-vl-max、gpt-4o、glm-4v-plus、doubao-seed 系列等支持图片输入的模型。

## 功能

- **上传即批**：拖拽 / 点击 / Ctrl+V 粘贴，多张连续页合并批改；全程可继续拖拽追加
- **批改白板**：AI 对错标注直接画在试卷照片上（默认只显错题红框，正确可开关）；单击编辑、双击改判、拖动调框，全部自动保存
- **手写批注**：打勾 / 打叉 / 画圈 / 自由书写 / 文字键入，六色可选，批注可拖拽移动，橡皮 / 撤销 / 清空
- **标准答案库**：上传答案图 AI 提取文本（可手动编辑修正，改完立即生效），全班同一份卷对照答案批改——更准更省 tokens；也支持纯手动录入答案
- **错题分析报告**：错题归类、逐题错因、知识点掌握率
- **给家长的小结**：问题 + 原因 + 3~5 条含频率的具体步骤，一键复制
- **AI 出题**：基于本卷错题现场编针对性新题
- **分层出题**：按累计学情自动分层——基础层(<60%)字词默写句子专项优先、巩固层(60~80%)变式强化、提升层(≥80%)拓展
- **双版本 PDF**：无答案版（学生练习）/ 答案版（教师用），判断选择题不加横线，分层卷带层级标题
- **学生档案**：成绩轨迹、累计知识点掌握、往期批改回看
- **批改精细度**（精简/详尽）与**模型推理开关**（自动/关闭/保持）独立可调；关闭推理提速约 3 倍
- **自定义批改要求**：预设控制条 + 自由文本，自动记忆

## 隐私

- 学生数据 `data.json`、试卷照片 `uploads/`、接口配置 `config.json`（含 Key）全部仅存本机，已被 .gitignore 排除，不会进入版本库
- 服务只监听 127.0.0.1；照片仅发送给你自己配置的 AI 接口
